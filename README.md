# ParkirMalang

ParkirMalang adalah website sederhana yang dibuat untuk membantu pengguna mengetahui informasi parkir di Kota Malang sebelum membayar parkir.

## Tentang proyek

Ide ParkirMalang berawal dari hal sederhana: sebelum membayar parkir, pengguna seharusnya bisa mengetahui apakah lokasi tersebut termasuk retribusi parkir, pajak parkir, atau masih belum terverifikasi.

Website ini masih dalam tahap pengembangan dan data yang tersedia akan terus diperbarui.

## Fitur

- Pencarian lokasi parkir
- Filter berdasarkan status parkir
- Tampilan lokasi pada peta
- Informasi tarif parkir
- Detail informasi setiap lokasi
- Navigasi menuju lokasi
- Fitur laporan jika informasi di lapangan berbeda

## Status

🚧 Masih dalam pengembangan.

Beberapa data yang ditampilkan saat ini masih berupa data contoh dan belum semuanya terverifikasi.

## Teknologi

- HTML
- CSS
- JavaScript
- Leaflet
- OpenStreetMap

## Tujuan

Membuat informasi parkir di Malang menjadi lebih mudah ditemukan dan dipahami oleh masyarakat.
